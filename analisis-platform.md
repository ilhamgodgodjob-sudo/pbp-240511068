# Analisis Komparatif Platform

## Bagian 2 — Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, dan TypeScript | Java, C#, C++, dan Python | Java, Kotlin, dan Swift |
| Arsitektur | Client-server, dengan aplikasi yang umumnya diakses melalui browser | Aplikasi berjalan pada sistem operasi komputer dan dapat menggunakan layanan lokal atau server | Aplikasi berjalan pada perangkat mobile dan dapat terhubung ke layanan server |
| Cara distribusi | Diakses melalui URL menggunakan browser | Diunduh melalui situs resmi, installer, atau toko aplikasi desktop | Didistribusikan melalui toko aplikasi seperti Google Play Store dan Apple App Store |
| Keunggulan | Mudah diakses tanpa instalasi khusus, lintas platform, dan mudah diperbarui | Dapat memanfaatkan sumber daya komputer dan mendukung fitur sistem operasi | Praktis, mudah dibawa, dan dapat memanfaatkan fitur perangkat seperti kamera serta GPS |
| Keterbatasan | Bergantung pada browser dan dapat memiliki keterbatasan akses perangkat | Umumnya perlu instalasi dan penyesuaian untuk sistem operasi tertentu | Memiliki keterbatasan ukuran layar, baterai, memori, dan kompatibilitas perangkat |
| Contoh aplikasi | Google Docs, Gmail, dan YouTube versi web | Visual Studio Code, Microsoft Word, dan VLC Media Player | WhatsApp, Google Maps, dan aplikasi mobile Gmail |

## Bagian 3 — Refleksi

Menurut saya, platform yang paling menarik untuk dipelajari adalah Mobile, khususnya pengembangan aplikasi Android. Saya memilih platform ini karena perangkat mobile sudah menjadi bagian dari kehidupan sehari-hari dan memiliki banyak fungsi yang memudahkan aktivitas manusia. Selain itu, saya tertarik untuk memahami bagaimana sebuah aplikasi dibuat, mulai dari proses pemrograman hingga dapat dijalankan pada smartphone. Dengan mempelajari platform Mobile, saya berharap dapat memperoleh pengetahuan dan keterampilan untuk membuat aplikasi Android sendiri di masa depan.

Selama melakukan setup environment, saya tidak mengalami kendala yang berarti. Proses instalasi tools dan persiapan lingkungan pengembangan dapat dilakukan dengan cukup lancar. Meskipun demikian, saya menyadari bahwa setiap tools memiliki fungsi dan cara penggunaan yang berbeda, sehingga tetap diperlukan pemahaman agar dapat digunakan dengan baik. Persiapan environment ini juga memberikan pengalaman awal dalam mengenal tools yang digunakan untuk kegiatan pemrograman.

Untuk mengatasi kemungkinan kendala di kemudian hari, saya berencana untuk terus berlatih menggunakan tools yang telah diinstal
